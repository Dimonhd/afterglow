# Afterglow — дизайн-документ

Постапокалиптический мод для Minecraft 1.21.1 (NeoForge 21.1.x, Java 21).
Этот файл — «память проекта»: сюда записывается всё, о чём просит автор.

## Требования автора (по порядку поступления)

1. Мод про постапокалипсис.
2. Версия: Minecraft 1.21.1, NeoForge.
3. Электричество как в реальной жизни, со всеми законами физики:
   вольт (В), ампер (А), ватт (Вт), ом (Ом), фарад (Ф), джоуль (Дж), генри (Гн) и т.д.
4. Ток обязательно должен течь: цепь «источник + выключатель + лампочка»
   не работает, пока цепь не замкнута.
5. Первые предметы: источник напряжения с возможностью управления, провода,
   лампочка, выключатель, цоколь для лампочки.
6. Автор будет добавлять новые механики и предметы — всё запоминать здесь.

## Физическая модель

Расчёт — модифицированный узловой анализ (MNA) на чистой Java, пакет
`com.afterglow.physics` (без зависимостей от Minecraft, проверяется отдельно).

| Элемент | Модель |
|---|---|
| Источник напряжения | ЭДС E + внутреннее сопротивление r (эквивалент Нортона) |
| Резистор / провод / лампа | закон Ома, I = U / R |
| Выключатель | замкнут: R = 1 мОм; разомкнут: нет связи |
| Конденсатор (Ф) | компаньон-модель (обратный Эйлер): G = C/dt + источник тока истории |
| Катушка (Гн) | компаньон-модель: G = dt/L + источник тока истории |
| Мощность | P = U·I, энергия E = ∫P dt (Дж) |

Шаг моделирования: dt = 0,05 с (1 тик). Конденсаторы и катушки уже поддержаны
решателем, но предметов с ними пока нет.

### Правила цепи
- Ток течёт только по замкнутому контуру; разомкнутая цепь даёт I = 0.
- Каждый блок провода — узел; стык двух проводов имеет сопротивление 0,02 Ом,
  контакт провод—вывод — 0,01 Ом, поэтому длинные провода дают падение напряжения.
- У двухполюсных компонентов (источник, выключатель, цоколь) два вывода:
  на лицевой грани и на противоположной. Провод к боковой грани не подключается.
- У источника лицевая грань — «+», противоположная — «−».

## Предметы v0.1

| Предмет | Описание |
|---|---|
| Источник питания | 0–48 В, ПКМ: +1 В, Shift+ПКМ: −1 В. r = 0,5 Ом |
| Провод | узел, соединяется со всеми соседними проводами и выводами |
| Выключатель | ПКМ переключает |
| Цоколь | ПКМ с лампой — вставить, пустой рукой — достать |
| Лампа накаливания | 12 В / 10 Вт (R = U²/P = 14,4 Ом); яркость ∝ P/Pном; перегорает при P > 2·Pном дольше 2 с |

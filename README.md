# Afterglow — электричество для постапокалипсиса (Minecraft 1.21.1, NeoForge)

Подробности и правила физики: `docs/DESIGN.md`.

## Сборка и запуск
Нужен JDK 21 и доступ в интернет (Gradle скачает NeoForge и Minecraft).

    ./gradlew runClient      # запуск клиента для теста
    ./gradlew build          # jar появится в build/libs/

Если версия NeoForge `21.1.172` из `gradle.properties` не находится, укажите любую
актуальную `21.1.x`. Версия плагина `net.neoforged.moddev` в `build.gradle` — тоже
можно обновить.

## Как играть
1. Поставьте **Источник питания** (лицевая грань — «+», красная; противоположная — «−», синяя).
   ПКМ: +1 В, Shift+ПКМ: −1 В (0–48 В). В action bar видны напряжение, ток и мощность.
2. Соедините выводы **проводами** с **цоколем** и **выключателем** в замкнутый контур.
   Провод подключается только к выводам (концам) компонентов, а не к боковым граням.
3. ПКМ **лампой** по цоколю — вставить, пустой рукой — вынуть.
4. ПКМ по выключателю — замкнуть/разомкнуть. Пока цепь не замкнута, ток не течёт.

Лампа 12 В / 10 Вт: яркость ∝ P/Pном. При P > 2·Pном дольше 2 с перегорает.

## Проверка физики без Minecraft
    mkdir -p /tmp/out && javac -d /tmp/out src/main/java/com/afterglow/physics/*.java src/test/java/com/afterglow/physics/PhysicsSelfTest.java
    java -cp /tmp/out com.afterglow.physics.PhysicsSelfTest

## Ресурсы
Текстуры, модели, blockstates, рецепты и переводы генерирует `python3 tools/gen_assets.py`
(нужен Pillow). Правьте скрипт и запускайте заново.
